# DFAST 1.6.0 (Prodigal, Diced, no bundled executables) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Prodigal the default CDS predictor (MGA via `--use_mga`), replace CRT with Diced, remove RNAmmer and `bin/`, and support translation tables 4 and 25.

**Architecture:** Same tool/config architecture as now: tools in `dfc/tools/` registered in `structuralAnnotation.TOOLS`, enabled through `default_config.py` entries and helpers in `config_util.py` driven by CLI flags in `dfast`. Diced is a Python package called in-process from a new `StructuralAnnotationTool` subclass.

**Tech Stack:** Python 3.10+, Biopython, Prodigal 2.6.3 executable, diced >= 0.1.4 (PyPI), MGA from Bioconda `metagene_annotator` (optional), pytest.

**Spec:** `docs/superpowers/specs/2026-11-05-v1.6.0-design.md`

## Review Focus

1. Input with runs of N (assembly gaps): Prodigal may call CDSs across them; the existing assembly_gap overlap handling must still remove or keep them as with MGA. Test in Task 2 (`test_prodigal_cds_across_gap_removed`).
2. Lowercase / soft-masked input to Diced: CRISPRs must be found as for uppercase. Test in Task 4 (`test_diced_lowercase_input`).
3. A CRISPR touching a contig end: location must be partial (`BeforePosition(0)` / `AfterPosition(len)`), like CRT. Test in Task 4 (`test_diced_crispr_at_contig_end`).
4. A Prodigal gene partial at both ends (`partial=11`, a short contig inside one gene): location must carry both partial markers and `codon_start` from the left offset. Test in Task 1 (`test_parse_both_ends_partial`).
5. `--gcode 25` with `--use_mga`, with `--metagenome`, or with input < 20 kb: must stop with an explanatory error, never run with table 11 silently. Tests in Tasks 1 and 2.
